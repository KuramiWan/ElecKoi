# ElecKoi v0.2.7

本版本为 Windows 预发布版本。

## 聊天修复

- 修复删除用户输入或 AI 回复后，AI 头像、正文和序号残留或重新出现。
- 修复删除后继续发送或重新生成时，用户消息短暂消失、历史正文被覆盖，以及 AI 回复在流式结束后消失。
- 修复重新生成关联错误输入、重复输入短暂显示两次，以及取消生成后操作持续锁定。
- 修复来回切换聊天时，标题已经切换但富文本正文仍来自上一会话。

### 根因与处理

聊天正文曾同时来自产品详情和 DSH Session，界面还会从残留的流式状态重建回复；删除及重新生成时，这些快照互相覆盖。现在正文统一采用同一 DSH Session 的正式投影，产品详情只提供元数据，流式状态只负责运行状态与停止操作。旧订阅按代次和绑定身份失效，临时输入通过 requestId 衔接正式消息，重新生成按明确的 Session 与轮次关联定位输入，不再按角色或正文猜测。

跨会话串台另有明确原因：各会话的开场消息都使用局部 ID `opening`，显示状态复用没有先检查所属会话，导致旧富文本正文被带入新会话。现在先核对会话与 DSH Session，再复用消息显示状态、渲染身份和过程信息。

## 界面调整

- 预设资料、使用说明和更新记录增加明确区域边界；使用状态与启用按钮紧邻预设名称，空更新记录居中显示。
- 统一侧栏图标线条、选中及悬停状态，改善深色主题下的对比度。

## 下载

Windows x64 用户下载本发行版附件中的 `*-setup.exe` 安装包。源码压缩包不是安装程序。
