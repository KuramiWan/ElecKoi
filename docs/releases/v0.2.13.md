# ElecKoi v0.2.13

本次新增 DeepSeek 网页搜索与抓取，修复完整工具结果读取、大量变量保存和 Windows 更新恢复，并完善聊天删除后的资源清理。

## DeepSeek 网页搜索与抓取

- 联网搜索配置新增 DeepSeek Search 和 DeepSeek Fetch，可分别选择搜索及网页抓取方式；角色对话与 AI 创作工作室共用现有联网工具。
- 支持独立保存联网 API Key、测试两种接口、设置每次 1–50 条搜索结果，以及选择同时获取网页正文和地域参数。保留原有模型搜索、Tavily 与直接 HTTP 抓取。
- 搜索保留来源、摘要、正文及排序等信息，抓取保留完整 Markdown，不再受旧预设固定返回条数和正文裁剪影响。
- API 未提供的源站 HTTP 状态明确显示为未提供；余额不足、限流、超时及网页访问失败会返回具体错误，取消或卸载时停止未完成请求。

## 完整工具结果与大量变量

- 修复完整工具结果存储没有正确装配到实际 Host 的问题，设定库、剧情变量和创作能力通过原有入口继续读取、搜索完整结果。
- 大结果沿用官方溢出保存和会话授权，续读写操作的回执不会再次执行原操作；正常摘要压缩保留。
- 修复一次保存大量变量时超过 SQLite 参数预算的问题，同一事务内完整保存变量与对象，保留全部有效条目。

## 聊天资源清理

- 删除聊天时，一并清理所属会话及被删除子会话的完整工具结果和归属记录；删除角色及独立创作工作室聊天沿用相同清理流程。
- 保留其他聊天的结果，拒绝越过结果存储目录删除文件。文件被占用或资源清理失败时记录具体原因，聊天删除仍可完成。

## Windows 更新

- 更新下载、校验与安装状态使用锁定 DSH Desktop 的更新控制流程，处理下载中断、停滞、校验失败和重试恢复。
- 合并重复下载请求，复用仍有效的已下载文件；失败后释放更新任务状态，保持现有更新入口与安装确认。

## Android

- 同时提供 ARM64 标准版与兼容版：标准版使用系统 WebView，兼容版内置 GeckoView。
- 两版共用本次 DeepSeek 搜索与抓取、完整工具结果读取、大量变量保存及聊天资源清理的实现。
- 两版沿用正式包名与签名，版本均为 v0.2.13、versionCode 8，可覆盖升级。
