# ElecKoi v0.2.12

电子爱由 DeepSeek Harness（DSH）驱动，提供 Agent 角色扮演与角色卡创作能力。本次更新完善工具结果读取、插件界面与聊天恢复，并修复消息编辑操作。

## 完整工具结果读取

- 设定库、剧情变量与创作能力可在原有读取或调用入口中继续读取、搜索完整的大结果，沿用各工具组的启停权限。
- 大量设定和长正文不再因额外的总量限制、中段裁剪或命中行截断而缺失，末尾关键词与全部有效命中均可查找。
- 大结果继续使用官方溢出存储，按当前会话授权续读；明确的分页输出不再重复溢出，读取写入回执不会再次执行原操作。
- 保留正常摘要压缩，恢复已保存预设时移除旧裁剪器。

## 插件工具与聊天显示

- 修复角色预设额外屏蔽第三方插件工具的问题，已启用的插件能力遵循 DSH 的注册策略和生命周期。
- 插件消息交回对应渲染器，工具、模型重试和失败详情归入所属 AI 楼层的处理过程，保留可见错误入口与历史回放。
- 压缩状态和独立插件卡片共用聊天阅读边界，跟随正文宽度、头像与间距设置，修复内容偏向左侧和布局不一致的问题。

## AI 创作工作室

- 顶部页签支持已安装插件提供的视图，并可打开官方右侧栏，使用当前对话的插件工作台和其他侧栏页面。
- 修复后台会话引用干扰侧栏跟随的问题，统一独立操作按钮的尺寸，保留组合按钮与下拉菜单布局。
- 删除当前选中的角色后，原有工作室聊天仍可打开并继续发送；新建对话不再继承失效角色，角色专属操作仍要求选择有效角色。

## 聊天与编辑

- 切换角色扮演与创作预设时保留当前编辑区域，待目标详情就绪后交接，减少整页闪动。
- 修复移动聊天编辑已有消息时，键盘展开状态下首次点击取消或保存可能失效的问题；操作完成前保留当前输入模式与焦点。
- Windows 安装继续修复低完整性标记目录导致的启动失败，保留既有访问权限和用户数据。

## Android

- 同时提供 ARM64 标准版与兼容版：标准版使用系统 WebView，兼容版内置 GeckoView。
- 两版共用当前聊天、角色、预设、工具及创作工作室实现，包含本次完整工具结果读取、插件界面和移动消息编辑修复。
- 两版沿用正式包名与签名，版本均为 v0.2.12、versionCode 7，可覆盖升级。
