# ElecKoi v0.2.9

本版本为 Windows 预发布版本。

## 自动配图

- 角色回复支持自动配图，可在工具配置中选择 NovelAI 绘图配置与参数。
- 图片随回复显示，支持查看提示词、下载和单张重绘；生成失败时保留已有图片。
- 配图与所属聊天消息关联，删除或回退消息时清理不再使用的图片。

## AI 创作工作室

- 新增独立的创作工作室会话，选择角色后，AI 可协助修改角色资料、设定、变量、脚本和正则。
- 支持编写 EJS 设定、配置和校验 Zod 变量规则，以及测试正则显示替换。
- 创作预设与角色扮演预设分别管理和选择；已有预设保留为角色扮演用途。
- 工作室保留完整创作上下文，退出后可继续同一会话。

## 脚本、作者页面与内容导入

- 提供 ElecKoi 原生作者 SDK，支持变量规则、聊天脚本按钮、设置面板和作者页面。
- 全局、角色和预设分别管理脚本；输入菜单中的“脚本”入口可打开已注册的操作。
- 脚本与作者页面使用实际源码文件，支持相对资源引用；作者教程附带完整接口参考和可导入示例。
- 角色卡、预设、设定、正则及变量配置导入后统一进入对应的原生资料；导入失败时保留有效内容并说明原因。
- HTML 卡片所需的浏览器库和资源由项目自己的资源模块提供。

## 编辑与聊天体验

- 整理角色、预设、设定和变量编辑页的布局与导航，完善搜索、保存反馈和批量角色操作。
- 修正消息正文间距、附件预览与输入文字重叠等显示问题。
- 完善正则处理与互动 HTML 显示、脚本启停和面板清理，移除已停用的旧脚本运行器与无用依赖。

## 下载

Windows x64 用户下载本发行版附件中的 `ElecKoi-0.2.9-x64-setup.exe` 安装包。源码压缩包不是安装程序。
