# ElecKoi v0.2.10

本次 PC 更新修复正则与互动 HTML 显示、自动更新检查，并补齐 AI 创作工作室的模型参数和从零创建角色能力。

## 正则与互动内容

- 显示正则现在使用完整 AI 回复，回复中的时间栏、状态栏和选项可一起参与替换。
- 回复正文继续流式显示，回复结束后再执行显示替换，减少原文与互动页面反复切换造成的内容消失和跳动。
- 互动 HTML 完成加载并返回高度后再显示；刷新保留已有页面及变量输入，窗口宽度变化时重新确认内容高度。

## AI 创作工作室

- 模型选择器可以编辑并保存模型参数，创作请求按当前选择的模型读取已保存配置。
- AI 可以直接新建空角色，自动将新角色设为当前工作室的编辑目标，并继续填写资料和设定。
- 新建角色只更新当前工作室的绑定，保持其他工作室和角色对话独立；关闭后重新打开仍可恢复编辑目标。

## 自动更新

- 更新检查改为通过 GitHub 官方 API 读取发布信息和附件。
- Windows 安装包包含完整更新配置，修复缺少配置时检查更新直接失败的问题。
