# ElecKoi v0.2.11

本版本提供 Windows x64 与 Android ARM64 安装包。电子爱由 DeepSeek Harness（DSH）驱动，提供 Agent 角色扮演与角色卡创作能力。

## EJS 显示模板与配置版本

- 角色与预设新增 EJS 显示模板，支持在共享全局、预设和角色作用域按历史变量生成 AI 消息界面，并提供源码测试及沉浸编辑。
- 设定、变量、正则、脚本和显示模板统一完整版本管理，可复制、切换、重命名、导入和导出配置；脚本版本包含源码与资源。
- 正则、显示模板和脚本的分组标题开关支持批量启停全部条目，多选操作和保存状态保持一致；跨窗口编辑使用修订号与资源摘要拒绝覆盖冲突。
- 新建脚本源码留空，允许保存空白、停用的草稿；启用空源码时明确提示错误。

## 模型配置与 AI 创作工作室

- 模型配置改为独立配置列表，支持自定义 Provider ID、DSH 官方提供商目录、Google 原生生成协议，以及 OpenAI Images 和 NovelAI 绘画模型入口。
- 模型选择、添加、读取和删除操作统一布局，推理档位与图像能力依据实际适配器和目录声明提供。
- 创作工具补齐显示模板、完整配置版本、批量设定与分组、变量和上传文件读取，并支持明确指定全局或预设作用域。
- 作者 SDK 的教程、接口参考、网页及可导入示例同步当前合同，提供模板与配置版本接口。

## 富消息与阅读体验

- 设置 → 聊天显示 → 富消息新增运行楼层限制，默认关闭；开启后默认自动运行最近 5 个已完成 AI 消息楼层，可设置为 1–100 楼，较早卡片按需加载。
- 超出运行范围的网页会卸载并释放 SDK 绑定，同时最多额外运行一个手动加载的旧楼层；阅读位置继续由官方聊天视图管理。
- 修复首次高度测量依赖动画帧导致互动内容延迟出现的问题，并保留后续尺寸变化的按帧合并。
- 修复深色模式下透明圆角出现白底、正文高亮残留、长内容溢出及消息删除后置底按钮偏移，补充前端加载与渲染诊断。
- 重新计算显示内容时保留有效旧界面，取消过期计算，减少重复渲染和长会话投影开销。

## 聊天、重新生成与历史状态

- 对话切换和同一聊天重新生成保留已就绪的显示引用，减少输入框和页面短暂消失；回退与重新生成保持同一聊天及 Session ID。
- 删除角色或整条对话后，及时清空当前页面并关闭所属前端、撤销旧 SDK 绑定，未完成的打开操作不会恢复已删除的聊天。
- 单独删除对话保留角色及其前端项目；删除角色继续清除关联聊天和该角色的专属资源。
- 处理状态以单行持续更新，模型重试次数、等待和错误进入「处理过程」弹窗，正文下方不再重复展示重试记录。
- 历史变量和分支设定按输入与回复边界保存，变量查看器与聊天归档使用相同状态来源；缺失历史状态明确提示。
- 自定义压缩模板保留官方选择的历史消息、工具声明与请求参数，只替换摘要指令。
- 停止官方工作区在后台自动选择、创建和恢复会话，启动导航由角色聊天与创作工作室负责。

## 编辑器与插件恢复

- 统一桌面搜索、新建、多选、管理、版本操作、右键菜单和侧栏材质，调整品牌字标、标题栏对齐与侧栏展开收起动画。
- 模板、脚本及设定等编辑器保持完整内容，减少重复入口和无业务用途的长度截断。
- 原生错误对话框提供停用用户插件并重启入口，在 Host 或客户端无法启动时仍可处理，保留内置功能、已安装插件包和产品数据。
- 保留应用许可证、Electron 及第三方组件声明，Windows 安装包继续由 GitHub 发布流程构建。

## Windows 安装修复

- 修复安装到带有低完整性标记的目录后，应用可能在窗口出现前退出的问题。
- 安装器在启动应用前恢复主程序、运行库和安装辅助程序的正常完整性级别，保留原有访问权限、上级目录与用户数据；无法完成时明确提示安装失败。

## Android

- 同时提供标准版与兼容版：标准版使用系统 WebView，兼容版内置 GeckoView，无需额外安装浏览器。
- 两版共享聊天、角色、预设和工具实现，沿用同一正式包名与签名，可直接覆盖安装及切换版本，无需卸载或清除数据。
- 两版下拉选择统一提供取消、已选状态、禁用项、分组与多选；修复兼容版下拉菜单无法使用的问题。
- 角色与预设编辑的搜索、多选、管理恢复同一行布局，修复并入列表选择框和搜索框尺寸；预设提示词补充多选与批量操作。
- 移动侧栏使用统一品牌字标，显示模板与脚本支持双击编辑，共享富消息渲染和运行楼层设置。
