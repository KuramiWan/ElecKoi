# 联网搜索与网页抓取

PC、Android 标准版和兼容版使用同一套联网工具。对话所用预设需要启用「联网搜索」工具组；它包含 `web_search` 和 `web_fetch`，分别负责找资料和读取指定网页。

## 配置

1. 打开联网搜索配置，搜索方式选择「DeepSeek Search」，网页抓取选择「DeepSeek Fetch」。也可以独立搭配现有模型搜索、Tavily 或直接抓取。
2. 填写 DeepSeek API Key，点击「保存并测试」。测试会各调用一次 Search 与 Fetch，成功后密钥保存到官方 Credentials。它们都是收费 API；使用 DSH 账户登录不等于已经配置独立 API Key。
3. 搜索默认返回 10 条，可按官方范围设置为 1–50 条；需要时开启「同时获取网页正文」。地域 IP 可留空，也可以按官方 API 填写。

默认凭据引用为 `DEEPSEEK_WEB_API_KEY`，与聊天模型密钥分开。若明确希望使用已有凭据，可在「凭据引用」填写其正式引用名；移除按钮会删除当前引用对应的凭据，使用共享引用时也会影响使用该引用的其他功能。页面只读取凭据配置状态，不显示已保存密钥正文。

## 结果与错误

Search 返回来源、日期、摘要、片段、正文和排序等原始字段，不将结果静默裁成旧版固定条数。Fetch 保留完整 Markdown；官方接口没有提供源站 HTTP 状态和最终跳转地址，因此工具保留请求 URL 并明确显示「源站 HTTP 状态未提供」。直接抓取仍显示它实际收到的 HTTP 状态。

长结果沿用 DSH 已有输出和溢出保存机制。余额不足、无效密钥、限流、超时或网页不可访问会明确报错，不自动换提供商。停止请求或卸载提供器会取消进行中的请求。
