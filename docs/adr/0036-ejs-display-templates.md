# ADR 0036：独立 EJS显示模板

状态：已实施。共用 Web/Host 逻辑及浏览器验证完成；Android 真机安装与系统能力验收另行记录。

## 问题

固定捕获组替换不适合选项数量可变、需要计算或按变量选择布局的消息界面。设定 EJS 的输出进入模型工具结果，不能把显示 HTML 混进这条链。角色和预设需要独立入口，并保持同一预设从不同页面修改时的数据一致性。

## 决定

1. 角色配置和预设编辑各有「EJS显示模板」。预设脚本入口补齐；正则、脚本和显示模板在角色编辑器只展示全局和角色，在预设编辑器只展示全局和明确选中的预设。共享全局配置共用持久化与变更通知，不设置额外的全局配置页面。编辑保存不覆盖其他归属，聊天运行时仍依次使用全局、当前扮演预设和角色。
2. `display_template_libraries` 归产品 Host Repository，按 `scope + ownerId` 唯一，外键关联角色或预设。结构版本统一为 v11→v12 的单步原子迁移。库使用 revision 比较保存；其他窗口保存后，干净编辑器刷新，脏草稿保留并报告冲突。
3. 查询、命令和通知走锁定 DSH 的 Typert Remote 与配置变更流。Android 标准版、兼容版和 PC 共用 Web Client、Host 领域模型及合同。
4. 使用精确锁定的 EJS 3.1.10 浏览器引擎。每次计算在独立 Web Worker 中，结束、超时或取消都终止 Worker。输入为不可变的消息原文和历史变量快照；缺失快照不能用当前变量替代。模板计算不暴露业务 SDK、Node 或应用 DOM，不宣称 Worker 可以沙箱化任意不可信 JavaScript。
5. 流式正文继续显示，分片不执行显示模板。完成后计算一次，结果交给现有 HTML 消息与 Markdown 显示链；配置保存后重新计算已有消息。重新计算及新文档加载期间保留同一原文的已接受显示结果，过期计算不能写回另一消息。库归属和 revision 不变时复用配置快照，其他角色的变更不触发当前模板重算。
6. 显示正则先运行。`content` 为正则及前序模板替换后的正文，`rawContent` 为完整 AI 原文。模板可自行解析原文；replace 模式匹配 content。库顺序为全局、当前扮演预设、角色；库内按配置顺序计算 before、replace、after。
7. 每个模板独立计算，不提供共用片段或模板引用。计算超过 3 秒或输出超过 200 万字符中止；单个模板失败保留此前有效正文，不伪装成功。
8. 显示模板不进入角色扮演请求、设定注入工具结果或消息存储；创作工作室明确读取模板时，源码作为创作工具结果返回。显示交互由输出 HTML 的作者 SDK 处理。导出角色卡与预设使用 `ejs_display_templates` 字段；导入保留源码并停用库。模板库与原生脚本库一样独立于设定版本，不随设定版本切换。

## 后果

SDK 提供共享全局、绑定角色及当前扮演预设的显示模板读写方法；创作工作室通过明确目标维护模板和预设脚本。教程列出标准语法、数据来源、执行时机和失败边界。浏览器验收与设备验收分开记录，不以编译结果代替 Android 真机验证。

全局显示模板使用正式 `scope="global"` 和空 `ownerId`，不依赖是否有当前角色或预设。v11→v12 升级直接建立包含全局归属约束的正式结构。编辑器多库保存为原子事务；角色卡和预设传输仅携带其自身模板。正则编辑合同独立于运行组合，只暴露允许范围，保存合并保留其他归属的启用版本成员。
