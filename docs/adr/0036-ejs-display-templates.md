# ADR 0036：EJS 归入正则替换

状态：替代原独立显示模板方案；预设与角色卡共用正则入口。

## 问题

独立显示模板重复了正则的匹配、替换、启停和排序，还增加消息前后插入模式、独立存储与教程。正则已经能携带前端源码，EJS 应当是其替换内容的计算能力。

## 决定

1. 删除预设和角色卡编辑中的独立显示模板入口、Client 模型、Remote、作者 SDK 管理接口、创作能力组及导入导出字段。不转换旧模板，不创建兼容入口。
2. 保留现有全局、预设、角色正则的完整配置。先按作用对象、仅显示／仅提示词、深度、启停和顺序完成正则替换，再对正则替换写入的代码计算一次标准 EJS 3.1.10。结果不递归执行。显示 HTML 继续走现有富消息渲染。
3. EJS 条件、循环、计算、标准转义与 await 共用同一计算合同。显示侧读取消息历史变量快照，提示词侧读取本次请求变量快照；缺失时明确报告，不能伪造其他时间的变量。计算不提供产品 SDK，输出网页使用原生作者 SDK。
4. 显示计算在 Web Worker 中执行，流式完成后计算；内容变化或页面关闭取消旧计算。Host 请求计算使用独立 Worker 与 JavaScript realm，不传入 Host 对象，在正式 llm/stream 请求投影后、实际发包及预览捕获前执行；不改 Session 消息。Worker 结束或取消即释放，不另设模板数量、输出长度和固定执行秒数限制，不宣称能够沙箱化任意不可信 JavaScript。
5. 数据库正式升级 v12→v13，删除 display_template_libraries 和该类型的编辑器版本，保留正则与脚本版本原始内容。此步骤仅删除已废弃的存储，不将旧 EJS 配置迁入正则，也不增加运行时双轨。历史版本化数据库升级链保留，以支持既有数据库连续升级；不能因为本机已运行就删除其步骤。

## 后果

用户只学习正则、EJS 语法和独立脚本的各自职责。预设与角色卡的 UI、Host、Client、创作工具、SDK、文档和可导入示例保持一套合同。回归覆盖作用范围、顺序、捕获、可变选项、大输出、历史快照、取消、实际模型请求、数据库重开及两类编辑入口。
