# ADR 0025：同一 Session 复用已有用户事件重新生成

状态：已采纳，2026-10-06。

## 根因与基准

基准为 DSH 提交 `c1b47e41fcd54d20a0f061df28683bfc29ee24e5`。该版本普通 `Agent.followup` 会把输入加入 inbox，再在首个 step 写入新的 `user/message`；它没有从既有用户事件继续运行的公开入口。

此前产品重新生成先撤销包含用户事件的整轮，再调用 followup 重发。原用户事件的 seq、消息 ID 与请求身份随之改变，Client 只能在两次 Session 快照之间用正文副本补行。编辑、删除及流式运行因此存在交接空挡，不能靠呈现层补行解决。

## 决定

1. 用户事件保留在原 Session 日志中。重新生成按明确 eventSeq 截断其后的事件；保留原消息 ID、seq、时间、附件和 source。已有开放边界由同版本官方 `interruptedTurnClosers` 闭合，编码、恢复和校验仍使用官方 format catalog，不建立 Session 分叉。
2. 编辑并重新生成先通过正式消息编辑服务更新该事件，再截断其后的输出；两项操作属于同一日志事务。生成端重新读取 Session 当前 surface 的明确消息 ID，不缓存或重发编辑前正文。
3. 在受管 DSH 运行时中为锁定的 agent-loop 增加明确 `continueFromInput(messageId)` 入口。这是产品需求所需的有限上游扩展，不声称它是该版本的官方 API。入口只接受 idle、无待处理 inbox 的 Agent 与现存直接用户输入；只跳过这条已提交事件的再次写入，其他 pre-step 插件、系统提示、请求、工具、流式、错误和取消生命周期保持官方执行路径。普通 followup 不改变。
4. 每次继续运行返回新的 DSH turn 编号，并在 Session 记录 `eleckoi/input-continuation` 的明确 turn、inputMessageId 与 inputEventSeq 关系；记录携带 `ignorable: true` 信息性信封，不改变模型 surface，正式 projection 将关系传给 Client。重复重新生成、编辑和重开聊天都按该身份选中原输入，不按角色、内容或相邻位置猜配对。Client 按执行身份等待 `turn/end`，不依赖新用户消息或新的 source.rpcId。删除单条 AI 回复保留其用户事件，不删除再追加它。
5. 删除所有重新生成正文副本与过渡行。Session 是正文唯一来源，正式用户节点始终使用稳定身份。普通发送的官方 pending input 行仍只负责尚未提交的真实新输入。
6. 轨迹仍由实际装配的官方 `dsh-client-ui-trajectory` 定义与快照构建器负责。保留输入时闭合的旧 step 没有模型执行证据，不能被识别为失败请求；通过锁定包的有限修正区分 step 边界与模型请求，真实 attempt、chunk、retry、message 的错误仍保留。节点按官方组装器合同保留稳定 key，以无可见请求的空贡献结束输入边界，不在实时更新中撤回已发布节点。首个请求 header 尚未记录时保留已知初始系统提示正文作为比较基线，连续重写也与该基线比较；事件 ID、seq 或 surface 替换本身不是内容更新证据。相同正文不产生变更事实，真实正文差异仍进入请求详情。轨迹主列表保留初始提示，不追加“系统提示词已更新”说明行；每次请求的实际系统提示统一在该请求的“上下文”详情中核对。运行环境重组导致的提示差异不能被呈现为用户修改预设，工具定义变化继续单独展示；历史日志与模型请求不改变。
7. DSH turn 是执行编号，不等于产品聊天轮次。已有输入身份 projection 同时索引直接用户事件的 ID、seq 与所属执行 turn；Client 通过该索引和 continuation 的精确关系显示聊天轮次并安放已有输入。请求、工具、折叠与检查器继续使用原执行编号和事件身份，不重编号 Session、不按正文或相邻角色猜配对。
8. 轨迹、官方 TurnNavigator 的呈现适配和官方 StatsPills 的轮数都使用这一输入身份索引。继续执行更新原输入标记的回复预览，不增加聊天标记；删除与重开后从正式 projection 重建。统计保留官方耗时、速度和 token 数值，仅将执行 Turn 数转换成直接用户事件数；明确 continuation 引用的无请求闭合输入边界不计入生成步数，真实模型失败、取消与重试仍按官方生命周期计数。历史恢复与 continuation 的边界折扣按 ID、seq 去重；缓存只能桥接不存在的重载快照，正式零值必须清除旧值。

## 约束与验证

扩展通过精确依赖补丁登记，公开方法只在 Host 运行时边界调用；升级 DSH 时重新核对并优先采用满足同一语义的官方入口。覆盖编辑后生成、重复重新生成、单删 AI 后生成、正常发送、拒绝与取消，以及真实 Client 历史重载和运行状态固定挂载。轨迹回归执行实际安装的官方 Client bundle，覆盖保留输入后的完整事件序列、系统提示替换、真实模型失败与聊天轮次；不能用未装配的本地定义通过结果代替。测试只使用合成内容。
