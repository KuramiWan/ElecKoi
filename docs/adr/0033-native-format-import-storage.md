# ADR 0033：导入格式与原生数据存储

## 状态

已采纳。

## 决策

角色卡、预设、设定库、正则与聊天的外部格式只用于导入转换。导入结果由原生领域服务保存，不保留第二份可编辑业务数据，也不提供外部脚本运行服务。

移除独立的扩展注册数据库及其命令入口。正则选项属于原生正则规则，在已有规则表中保存；作者前端文件使用独立文件项目目录。不读取、迁移或复用废弃的扩展注册库，不创建通用文档表。

MVU 初始化数据与规则提取分别处理。无法提取规则时保留明确的初始化变量，并显示未导入的规则原因；初始化本身处理失败时保留设定与开场白中的原始内容并提示，不阻止其他角色资料导入，不声称变量规则已经支持。

普通 HTML 显示与原生作者 SDK 保持独立。导入不启用外部后台脚本，不改变原生模型请求组装规则。

HTML 所需的浏览器库、字体、样式与文档解析资源由 `@eleckoi/dsh-client-html-resources` 同一个产品插件提供。Host 通过正式 `webServer` 注册 `/eleckoi/html/`，Client 发布资源就绪状态；不再装配独立兼容 Host 和共享酒馆 Client，也不构建或分发旧酒馆运行器与其专用分词器、词表及业务依赖。MVU 包只保留当前导入和原生变量显示所需的格式处理。

现有 profile 使用官方读写合同一次性替换启用列表中的旧资源组合并移除废弃 bundle 身份。已完成旧版本登记的 profile，两个旧资源 bundle 任一未启用时保持资源停用，不重新启用其他用户关闭的 bundle；用户自己的 patch 与外部插件依赖保持原样。
