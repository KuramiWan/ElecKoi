# 创作内容与运行边界

角色、预设、提示词、设定库、变量、正则与 EJS、脚本、更新记录和创作项目不设置产品侧的字数或条数上限。导入、保存、重开、工具调用与请求组装使用相同合同。实际处理仍受设备内存、运行引擎、文件格式和所选模型接口的能力约束；失败必须说明原因，不能以截断冒充成功。

## 内容与导入

- 角色卡批量导入、导出不再限定 50 张。导出重名文件按实际冲突继续编号，不在 1000 次后拒绝。
- 角色卡、预设、正则 JSON、头像和脚本附件移除原来的固定文件大小上限；保留编码、格式、路径与归属检查。
- 预设任务移除 20 项及每项 2000 字的限制；持久化、旧版本升级读取与模型工具声明均完整保留。
- 变量补丁移除 200 项上限。变量规则不按固定一秒中止，校验诊断不截断条数或作者文案。
- 正则 EJS 替换源码及输出不设固定 1000 字限制。独立显示模板功能已经删除，当前入口为正则的「替换为」。
- NovelAI 提示词、编译指令及分镜总数不设产品上限；所选接口不接受的实际参数由服务明确报错，保留已经成功生成的结果。
- 作者页面 API 不再限定正文长度、请求大小、并发数量或调用频率。会话归属、方法权限及明确的协议身份校验保留。
- 模型手动配置不再使用统一四百万 Token 上限，也不强制上下文至少 4096、压缩阈值至少 1024 或温度至多 2；保存明确的合法数值，由所选正式适配器及模型执行自己的合同。压缩阈值与该上下文的关系、Top P 的概率范围继续校验。
- 预设、正则及启用版本的多条保存，在同一事务内复用预编译语句，避免把全部条目拼成一条 SQL 而超过参数预算。

## 读取与展示

变量及上传文件默认读取完整值，传入分页参数时按请求分页，不再强行缩小请求页或省略长子项。普通大结果仍由正式 Host 的溢出策略保存全文，通过原读取入口续读或搜索，不增加独立 AI 工具。设定、变量与创作能力工具组仍为 4／4／3 个成员。

聊天与轨迹列表的默认分页属于展示方式，返回继续读取的位置，不限制历史总量；显式页大小不被另外夹到 200 或 1000。轨迹工具树以迭代方式投影，不在 256 层截断；循环归属仍拒绝。标题、头像字母和列表摘要的缩略显示不改原正文。

创作画布撤销、重做不再只保存最近 50 次操作。富消息运行楼层限制默认关闭；作者主动开启时按自己填写的正整数运行，不再限定最多 100 楼。既有已保存的开关和数量不被重置。

## 外部合同与资源配置

- Tavily 搜索条数为官方 API 的 0–20；DeepSeek 搜索字段沿用锁定 DSH 官方插件合同。参见 [联网配置](WEB_SEARCH.md)。
- OpenAI 图像的尺寸、像素数、比例与步进沿用[官方图像参数](https://developers.openai.com/api/docs/guides/image-generation)；PNG 的关键字与单块长度遵守 [PNG 标准](https://www.w3.org/TR/png-3/)。
- 模型上下文和输出能力、用户设置的压缩触发点、关键词与正则的深度条件，以及作者编写的 Zod 条件继续有效。正常摘要压缩和可完整恢复的结果溢出保留。
- 锁定 DSH 的附件、HTTP 正文、指令读取、搜索批次及代理深度配置要求有限数值。产品配置使用 JavaScript 的最大安全整数表达没有额外业务配额；Connection 按官方 Base64 和请求外壳预算同步配置，不把旧的 4 张、20 MB、64 KB 或 3 次规则留在下一层。
- 网络取消、连接测试与官方网络超时、格式检查、无循环 JSON 和原有访问权限不属于字数或总量裁剪。缓存回收、日志轮转及窗口尺寸范围不限制作者保存的内容。

## 升级链

`0002RuntimeClean.ts` 的历史计划读取也移除了旧字数与条数限制，没有新增数据库版本或迁移。该文件随受支持旧版本的完整升级链保留；只有不再支持 schema v2 之前的数据库并移除其整条升级路径时，才能连同两个旧计划读取函数删除，入口注明 `RETIRE WHEN:`。
